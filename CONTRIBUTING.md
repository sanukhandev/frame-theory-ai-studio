# Contributing

Read [AGENTS.md](AGENTS.md) and the complete delivery backlog at [docs/EPICS_AND_TASKS.md](docs/EPICS_AND_TASKS.md) before changing code.

- Start from an unblocked issue ID (FT-xxx). Develop a small real vertical slice rather than a visual-only prototype.
- Keep Domain free of UI/native/network dependencies. Use test fixtures that are licensed and synthetic.
- Include tests and reproduction instructions for each feature or fix. Document OS/native limitations.
- Never commit raw creator footage, user-identifying media, Gemini keys, commercial fonts, proprietary effects or unapproved Frame Theory logo substitutes.
- Prefer feature branches and PRs; include a screenshot or screen recording only when it demonstrates a **functional** editor behavior.
- Do not choose a repository software license without owner approval. Native dependencies and bundled AI model weights require their own audit.
- Update docs/IMPLEMENTATION_STATUS.md and task status with actual results and links to commit/tests.
