# Approved Frame Theory logo

The official logo is provided in the Frame Theory project's source assets as **Elegant Frame Theory Monogram.png**. This Git repository deliberately contains **no substitute logo**. The maintainer must verify and import the exact approved bytes to `assets/brand/frame-theory-original.png` when authorized. See [docs/BRAND_ASSETS.md](../../docs/BRAND_ASSETS.md). Do not generate another logo, change proportions, recolor, or falsely label a synthetic monogram as official.
